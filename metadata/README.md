# Metadatos

Esta carpeta contiene información estructural sobre las conversaciones, separada del contenido original.

## Esquema provisional

- [`schema-v0.1.json`](schema-v0.1.json) define la estructura de un registro de episodio conceptual.
- [`episode-record-template.json`](episode-record-template.json) proporciona una plantilla mínima para nuevas anotaciones.

Los metadatos podrán incluir, entre otros campos:

- identificador de sesión y episodio;
- archivo fuente y marcadores de localización;
- estado epistemológico;
- tipo de intervención de la IA;
- calidad epistemológica;
- riesgo de complacencia;
- validez del salto conceptual;
- memoria y continuidad;
- estado de la evidencia;
- `EPISTEMIC_DELTA`.

Los metadatos descriptivos no deben alterar el corpus primario.

El esquema es experimental y podrá cambiar junto con la taxonomía.
