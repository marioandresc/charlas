# Metadatos

Esta carpeta contiene información estructural sobre las conversaciones, separada del contenido original.

Los metadatos podrán incluir, entre otros campos:

- identificador de sesión;
- fecha aproximada o fecha disponible;
- modelo utilizado, cuando pueda determinarse;
- relación con otras sesiones;
- tamaño y estructura del archivo;
- temas principales;
- estado de auditoría;
- estado de revisión de privacidad.

Los metadatos descriptivos no deben alterar el corpus primario.
