# Corpus

Esta carpeta documenta el material conversacional original.

## Principio de preservación

Las conversaciones originales son la fuente primaria del proyecto. Durante la fase de auditoría no se modificará su contenido ni se reinterpretarán dentro de los propios archivos originales.

La organización física de los archivos podrá cambiar posteriormente, pero cualquier transformación deberá ser trazable.

## Capas

- `raw/` — conversaciones originales, preservadas.
- `curated/` — copias o versiones preparadas para análisis, cuando sea necesario.

La separación entre material original y material procesado permite distinguir entre **registro histórico** y **análisis posterior**.
