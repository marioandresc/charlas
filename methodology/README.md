# Metodología

Esta carpeta documentará el marco conceptual y metodológico del proyecto.

## Pregunta central

> ¿Qué tan eficazmente puede un modelo de lenguaje actuar como contraparte epistemológica durante la construcción progresiva de conocimiento de un usuario?

La pregunta surge retrospectivamente de conversaciones que originalmente fueron mantenidas con fines de aprendizaje y exploración, no como experimentos controlados.

## Principio metodológico

Debe mantenerse una separación estricta entre:

1. lo que ocurrió en la conversación;
2. la interpretación posterior de ese episodio;
3. el caso experimental que eventualmente se derive de él.

Esta separación permite conservar la trazabilidad y evita convertir una interpretación posterior en un supuesto hecho histórico.
