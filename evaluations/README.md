# Evaluaciones

Esta carpeta contendrá casos de evaluación derivados de episodios reales del corpus.

El objetivo no es reducir las conversaciones a preguntas de respuesta factual. Los casos podrán evaluar:

- continuidad contextual;
- memoria y procedencia de información;
- razonamiento conceptual;
- detección de saltos inferenciales;
- resistencia a la complacencia;
- calibración epistemológica;
- consistencia longitudinal;
- capacidad de actuar como contraparte crítica durante la construcción de conocimiento.

No se crearán casos definitivos hasta completar la primera auditoría del corpus.
