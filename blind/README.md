# Piloto ciego de anotación v0.1

## Propósito

Estos tres episodios forman el primer piloto para comprobar si el esquema de grafo conceptual puede ser aplicado de manera independiente.

## Correspondencia de fuentes

| Código | Archivo fuente | Tema |
|---|---|---|
| P07 | conversación completa sobre ataques adversariales | ataques adversariales |
| P08 | `08-08-26 A Memoria Sesion Gemini.md` | disociación, atención y filtrado |
| P09 | `16-08-26 C Memoria Sesion Gemini.md` | memoria conceptual mediante fractales |

## Procedimiento

1. Lee primero el archivo fuente correspondiente.
2. No consultes ninguna carpeta `annotations/` antes de terminar.
3. No intentes reproducir una anotación existente.
4. Identifica 4–8 nodos conceptuales relevantes.
5. Atribuye actor, procedencia y relaciones.
6. Indica `CONCEPTUAL_TRAJECTORY`, `CLAIM_ESCALATION` y `EPISTEMIC_DELTA` cuando la evidencia lo permita.
7. Conserva `UNKNOWN` cuando exista ambigüedad real.
8. Envía la anotación por el chat, no modifiques estos archivos.
